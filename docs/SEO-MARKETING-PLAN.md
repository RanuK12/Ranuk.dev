# Ranuk.dev — SEO y captación de clientes

## Objetivo

Convertir búsquedas de alta intención en conversaciones comerciales para dos líneas: ingeniería Python/ML y servicios de Ranuk IT.

## Acciones técnicas inmediatas

- Mantener el sitemap limitado a rutas publicadas y enviarlo a Google Search Console.
- Verificar cada semana cobertura, Core Web Vitals, consultas y páginas con impresiones sin clics.
- Crear páginas indexables separadas para `desarrollo Python`, `machine learning aplicado`, `automatización de procesos`, `trading bots` y `auditoría WCAG/ADA`.
- Añadir un caso de estudio por servicio con problema, arquitectura, resultado y CTA.
- Medir `mailto`, formulario, Calendly y clics de GitHub/LinkedIn como conversiones.

## Contenido que atrae clientes

Publicar dos piezas semanales, reutilizables en LinkedIn y GitHub:

1. Caso técnico: antes/después, métrica, stack y decisión de arquitectura.
2. Guía práctica: forecasting, ETL, computer vision, MLOps o automatización para pymes.

Usar títulos con intención concreta: “Cómo automatizar X”, “Cuánto cuesta X”, “Python para X” y “Auditoría WCAG para X”. Cada pieza debe enlazar a un servicio y ofrecer una llamada de 15 minutos.

## Distribución

- LinkedIn: publicación personal desde Emilio + página Ranuk IT, con CTA a un caso concreto.
- GitHub: READMEs de proyectos destacados con demo, captura, arquitectura y enlace a ranuk.dev.
- Google Business Profile: categoría de consultoría informática, zonas Europa/LATAM y 3 casos verificables.
- Comunidades: respuestas útiles en Python, data y automatización; evitar promoción genérica.

## Embudo recomendado

Visita → caso de estudio → diagnóstico gratuito de 15 minutos → propuesta cerrada → retainer mensual.

Revisar semanalmente: sesiones orgánicas, CTR, formularios, llamadas agendadas, propuestas enviadas y tasa de cierre.
